# V2Mac Homebrew tap

```sh
brew install --cask v2macapp/tap/v2mac
```

Installs [V2Mac](https://v2macapp.github.io), a menu bar client for Xray-core (macOS 14 or later, Apple Silicon and Intel). The app is not notarized; the cask removes the quarantine flag so it opens without the Gatekeeper prompt.

Update with `brew upgrade --cask v2mac`.

Homebrew selects the DMG for your architecture. Secure Sandbox requires Apple Silicon and macOS 26 or later.
